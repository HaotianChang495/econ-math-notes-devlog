Development log for a personal site of economics and mathematics course notes: workflow, tooling, and lessons learned.

## Personal Takeaway 9/26/2026
#### Takeaways: Building a Toolkit for AI-Assisted Note Projects

- **Separate content from output.** One source per course; generate HTML from it.
  - 内容与成品分离：每门课一份源文件，网页由它生成。
- **Draft fast, finalize once.** Iterate on quick previews; run heavy steps only at the end.
  - 草稿求快，定稿一次：先用预览反复修改，重活最后只做一次。
- **Discuss before building.** Settle content in conversation first.
  - 先讨论，后生成：内容在对话里定好再动手。
- **Persist the toolkit.** Keep scripts, styles, and rules in the project.
  - 工具箱常驻：脚本、样式和规则存进 Project。
- **Keep only formats you read.** Every extra format costs time.
  - 只留用得上的格式：多一种格式，就多一份成本。
