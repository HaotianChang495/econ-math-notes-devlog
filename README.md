Development log for a personal site of economics and mathematics course notes: workflow, tooling, and lessons learned.

## Personal Takeaway 9/26/2026
#### Takeaways: Building a Toolkit for AI-Assisted Note Projects

- **Separate content from output.** Keep one plain-text source per course; generate HTML from it.
- **Draft fast, finalize once.** Iterate on lightweight previews; run heavy steps (formula pre-rendering, packaging) only at the end.
- **Discuss before generating.** Settle content in conversation, then build files.
- **Batch feedback.** Collect all revisions per round.
- **Persist the toolkit.** Store scripts, styles, and rules in the project so every new session starts ready.
- **Drop unused formats.** Each output format adds cost; keep only what you read.
